# DNN Platform Language Pack for Turkish (tr-TR)

Turkish (Türkiye) language pack for [DNN Platform](https://github.com/dnnsoftware/Dnn.Platform).

## Installation

Download `Dnn_Platform_Language-Pack-TR-TR_<version>.zip` from the [Releases](../../releases) page and install it in
DNN Platform under **Persona Bar > Settings > Extensions > Install Extension**. Each release also has a `.zip.sha256`
file you can use to verify the download.

Pick the release that matches your DNN Platform version; the Releases page lists every version. Pre-releases
(e.g. `10.4.0-rc3`) are built for the matching DNN Platform release candidate and are meant for testing only.

## Reporting issues

Found a wrong translation, or the pack doesn't install? [Open an issue](../../issues/new/choose) and pick the form
that fits: **Translation issue**, **Bug report** or **Enhancement**. Bugs that also happen in English belong in the
[DNN Platform repository](https://github.com/dnnsoftware/Dnn.Platform/issues).

## Contributing

Corrections and new translations are welcome, whether it's one string fixed in the browser or a larger update from a
DNN Platform site. See the [contributing guide](.github/CONTRIBUTING.md) and the
[Turkish translation style guide](.github/COMMON_TERMS.md).

Maintainers: the release process is described in [RELEASING.md](.github/RELEASING.md).
